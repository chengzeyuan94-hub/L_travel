# 旅行L叔 · 游戏与地图工坊

**0.2.4-public.1**：基于已验收的0.2.4-r2装配基线制作的公开版。包含完整Godot工程、三维城市与旅行四幕、地图/资源编辑工坊。个人非官方项目。

**公开版需先配置自有玩法规则。** 原80牌、原事件文本与相关供应/起始物资已清空；地图可编辑、保存、重开，四幕旅行与普通骆驼/船默认全开。正式商旅开局和工坊试玩会列出缺项并阻止空规则运行。未自行设计替代默认经济。

## 创作起点与致谢

下面是最初三个月、V0.1原型分享时的创作介绍；该段V0.1描述当时阶段，本次版本是0.2.4-public.1。

这是鳐鳐鱼的[《千年丝路》](https://yaofishgames.com/product/silk-road/)，也是我给孩子买的一款桌游。它把城市旅行、商品交易和路线选择结合起来，这套玩法给了我很大启发。于是我就想，能不能在这个基础上，做一次数字化的尝试？让程序帮忙提示流程、计算交易，再把地图上的城市变成立体建筑，让骆驼和小船真的动起来。今天给大家看的，是这个想法做了三个月之后的 V0.1 原型。商旅玩法的基础来自原作，我主要在画面、交互和自定义功能上做了一些尝试。

## 使用游戏与工坊

游戏标题进入四幕旅行，明信片/旅行本入口不需要额外胜场解锁。配置规则后，按界面设置2–4位本地玩家/AI、出发、骰子移动、比例贸易、推进回合。现有机制与规则可配置范围见RULES_CONFIGURATION.md；自定义策略仍需确认平衡与AI适用范围。

工坊可以新建自由地图、放城市、接陆海路线、编辑停靠点、绑定自有模型/图片、保存并重开。未配置玩法也可做这些编辑；正式试玩需完整校验，返回恢复工坊上下文。导入者须确认外部素材和规则的权利。私人18城规划地图未随公开源码分发。

Godot首次启动/首次绘制三维地图会导入资源、编译着色器，可能等待较久。来源不明音乐已排除，公开版无声；角色外部动作已换为自主程序动作，表现比私人版本简单。
